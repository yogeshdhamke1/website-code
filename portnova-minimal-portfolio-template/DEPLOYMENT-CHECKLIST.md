# Deployment Checklist

## Before Going Live

### Content Updates
- [ ] Replace all Unsplash images with your own
- [ ] Update contact information (email, phone, location)
- [ ] Add your own portfolio items
- [ ] Write your bio and about content
- [ ] Add real testimonials
- [ ] Create actual case studies
- [ ] Write blog posts
- [ ] Add real pricing packages
- [ ] Update FAQ with your questions
- [ ] Add your downloadable resources

### Branding
- [ ] Update logo/brand name from "PortNova"
- [ ] Customize color scheme in CSS variables
- [ ] Update fonts if needed
- [ ] Add favicon
- [ ] Create og-image.jpg for social sharing

### SEO & Meta
- [ ] Update all page titles
- [ ] Update all meta descriptions
- [ ] Replace domain in sitemap.xml
- [ ] Replace domain in robots.txt
- [ ] Update OpenGraph images
- [ ] Add Google Analytics code
- [ ] Submit sitemap to Google Search Console

### Legal & Compliance
- [ ] Customize Privacy Policy with your details
- [ ] Update Terms & Conditions
- [ ] Configure cookie consent preferences
- [ ] Add your business information to legal pages

### Technical
- [ ] Test all internal links
- [ ] Test contact form submission
- [ ] Verify Google Maps location
- [ ] Test on mobile devices
- [ ] Test on different browsers
- [ ] Optimize and compress images
- [ ] Minify CSS and JavaScript
- [ ] Remove link checker code from script.js
- [ ] Upload .htaccess (Apache) or web.config (IIS)
- [ ] Test 404 error page
- [ ] Test 500 error page

### Social Media
- [ ] Update social media links in footer
- [ ] Add real social media profiles
- [ ] Test social sharing

### Performance
- [ ] Run Google PageSpeed Insights
- [ ] Check mobile responsiveness
- [ ] Test loading speed
- [ ] Enable browser caching
- [ ] Enable GZIP compression
- [ ] Consider CDN for images

### Accessibility
- [ ] Test keyboard navigation
- [ ] Check color contrast
- [ ] Verify alt text on images
- [ ] Test with screen reader

### Final Checks
- [ ] Spell check all content
- [ ] Test all forms
- [ ] Check all dropdown menus
- [ ] Verify FAQ accordion works
- [ ] Test gallery lightbox
- [ ] Check portfolio filters
- [ ] Test cookie banner
- [ ] Verify all pages load correctly

## Post-Launch

- [ ] Submit to Google Search Console
- [ ] Submit to Bing Webmaster Tools
- [ ] Set up Google Analytics
- [ ] Monitor error logs
- [ ] Check broken links regularly
- [ ] Update content regularly
- [ ] Monitor site performance

## Server-Specific

### Apache Hosting
- [ ] Upload .htaccess file
- [ ] Verify mod_rewrite is enabled
- [ ] Test error pages

### IIS Hosting
- [ ] Upload web.config file
- [ ] Test error pages

### Static Hosting (Netlify/Vercel)
- [ ] Configure redirects
- [ ] Set up custom domain
- [ ] Enable HTTPS

## Quick Test URLs

After deployment, test these:
- Homepage: https://yourdomain.com/
- Non-existent page: https://yourdomain.com/fake-page.html (should show 404)
- All navigation links
- Contact form submission
- Gallery lightbox
- Portfolio filters
- FAQ accordion
- Cookie banner

## Notes

- Keep a backup of original files
- Test on staging environment first
- Monitor analytics after launch
- Collect user feedback
- Plan regular content updates
