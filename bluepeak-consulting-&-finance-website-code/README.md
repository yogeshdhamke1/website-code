# BluePeak Consulting Website

A modern, professional, and responsive website for BluePeak Consulting - a Financial Consultant and Business Advisory firm.

## Features

- **Responsive Design**: Mobile-first approach, optimized for all screen sizes
- **Professional Styling**: Clean, corporate design with trust-building elements
- **SEO Optimized**: Meta tags, structured data, sitemap, and semantic HTML
- **Accessibility Compliant**: WCAG guidelines, keyboard navigation, screen reader support
- **Fast Loading**: Optimized CSS, lazy loading, and performance best practices
- **Interactive Elements**: Smooth scrolling, form validation, animations

## Sections

1. **Header/Navigation**: Sticky navigation with mobile menu
2. **Hero Section**: Compelling headline with clear CTAs
3. **Services**: Five key service offerings with descriptions
4. **About/Expertise**: Company background, stats, and team
5. **Case Studies**: Three client success stories
6. **Testimonials**: Client reviews with ratings
7. **Contact**: Contact form with validation and company details
8. **Footer**: Links and copyright information

## Technical Stack

- **HTML5**: Semantic markup with proper structure
- **CSS3**: Modern styling with Flexbox/Grid, animations
- **JavaScript**: Interactive functionality, form handling
- **Fonts**: Google Fonts (Poppins, Inter)
- **Icons**: Unicode emojis for simplicity

## Color Palette

- Navy Blue: #0D3B66 (primary brand color)
- Accent Blue: #0078FF (CTAs and highlights)
- Cool Gray: #E6E9EF (backgrounds and subtle elements)
- White: #FFFFFF (main background)

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styles
├── script.js           # JavaScript functionality
├── sitemap.xml         # SEO sitemap
├── robots.txt          # Search engine instructions
└── README.md           # Documentation
```

## Setup Instructions

1. Clone or download the files
2. Open `index.html` in a web browser
3. For production: Upload files to web server
4. Update contact information and domain in sitemap.xml

## Customization

### Content Updates
- Edit text content directly in `index.html`
- Update contact information in the contact section
- Modify service descriptions and case studies

### Styling Changes
- Colors: Update CSS custom properties in `styles.css`
- Fonts: Change Google Fonts imports in HTML head
- Layout: Modify grid/flexbox properties in CSS

### Functionality
- Form handling: Update JavaScript in `script.js`
- Add new sections: Follow existing HTML structure
- Animations: Modify CSS animations and JavaScript observers

## Performance Optimization

- Images should be optimized and compressed (<200KB)
- Use WebP format for better compression
- Implement lazy loading for images
- Minify CSS and JavaScript for production

## SEO Considerations

- Update meta descriptions for specific pages
- Add structured data (JSON-LD) for organization info
- Optimize images with descriptive alt text
- Create additional pages for better keyword targeting
