## Image Optimization Tips

1. **Compress images** before uploading (use tools like TinyPNG)
2. **Use appropriate formats**: JPG for photos, PNG for graphics with transparency
3. **Optimize file sizes**: Keep under 200KB for web performance
4. **Use descriptive filenames**: `luna-portfolio-showcase.jpg` instead of `IMG_001.jpg`
5. **Add alt text** for accessibility
