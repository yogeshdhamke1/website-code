# Luna - Creative Photographer Portfolio

## Minimal Photography Portfolio Website

A clean, minimal photographer portfolio with grid layout, lightbox viewer, and modern design.

## Key Features

### Design
- **Minimal UI**: Clean, spacious design with focus on photography
- **Grid System**: 3-column responsive grid for portfolio images
- **Blur Navbar**: Navigation bar blurs on scroll with backdrop-filter
- **Grayscale Hover**: Images transition from grayscale to color on hover
- **Flat Design**: No rounded corners, minimal shadows

### Sections
1. **Hero** - Full-screen with photographer name and title
2. **About** - Profile photo, bio, and animated statistics
3. **Portfolio** - 9-image grid gallery with fancybox lightbox
4. **Services** - 4 photography services with images
5. **Testimonials** - 3 client reviews with photos
6. **Contact** - Simple contact form and social links

### Interactive Features
- **Fancybox Lightbox**: Click images to view full-screen with navigation
- **Animated Counters**: Statistics count up when scrolling into view
- **Back to Top**: Floating button with smooth scroll
- **Mobile Menu**: Slide-in navigation with close button
- **Smooth Scrolling**: All anchor links scroll smoothly

- **Headings**: Poppins (Light weight, uppercase, letter-spacing)

## Grid Layout
- **Desktop**: 3 columns
- **Tablet**: 2 columns
- **Mobile**: 1 column
- **Gap**: 1rem (minimal spacing)
- **Aspect Ratio**: 1:1 (square images)

## Navigation
- Transparent on load
- Blurs with white background on scroll (backdrop-filter: blur(20px))
- Minimal uppercase links
- Light font weight
- Active link highlighting

## Lightbox Features
- Full-screen image viewer
- Previous/Next navigation arrows
- Image counter (1/9, 2/9, etc.)
- Close button (×)
- Click outside to close
- Keyboard support:
  - Escape: Close
  - Arrow Left: Previous image

- Smooth zoom-in animation

## Quick Start
